# Protocol index

Protocols use the same numbering as `results/`. They document what was frozen
before each corresponding run or audit. The missing number 02 is intentional:
the published-mechanism comparison was a transparent adaptation audit rather
than a separately preregistered experiment.

- `01_identical_pool_selector/`: held-out identical-pool comparison.
- `03_multifamily_and_sensitivity/`: frozen multi-family panel and sensitivity.
- `04_supported_resource_stress/`: post-hoc E7b supported-resource audit.
- `05_component_attribution/`: archive and output-composer ablations.
- `06_cost_boundary_and_support/`: oracle, supply and replanning boundary work.
